# Programas (uso interno)

Estos son los scripts que hacen funcionar el organizador. No hace falta
abrirlos ni editarlos para el uso normal — para eso están los accesos
directos (`.bat`) en la carpeta de arriba.

- `bybit_sync.py` — trae el portafolio real desde Bybit.
- `mercadopago_processor.py` — procesa el CSV de MercadoPago y carga gastos.
- `generar_datos_html.py` — vuelca los datos del Excel al Dashboard.
- `bybit_config.txt` — tus claves de API de Bybit (no compartir, no subir a git).
- `config_toto.json` / `mis_reglas.json` — reglas de categorización de gastos.
- `tests/` — pruebas automáticas del código.
