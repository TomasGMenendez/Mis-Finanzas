# Mis Finanzas

Organizador de finanzas personales.

## Qué hay en esta carpeta

- **Finanzas_Toto.xlsx** — tu planilla con todos los datos: gastos, ingresos e inversiones.
- **Mi Dashboard de Finanzas.html** — abrila haciendo doble clic para ver un resumen visual de tus finanzas (gráficos, balance, portafolio). Se abre en el navegador.
- **Actualizar desde Bybit.bat** — hacé doble clic para traer tu portafolio real de Bybit y actualizar la planilla y el Dashboard.
- **Cargar gastos de MercadoPago.bat** — arrastrá el CSV que descargás de MercadoPago y soltalo arriba de este archivo (no lo abras con doble clic). Carga los gastos nuevos a la planilla y actualiza el Dashboard.
- **Programas** — carpeta con los scripts técnicos que hacen funcionar todo esto. No hace falta entrar ahí para el uso normal.

## Uso típico

1. Descargaste movimientos nuevos de MercadoPago → arrastralos sobre **Cargar gastos de MercadoPago.bat**.
2. Querés ver tu portafolio de cripto actualizado → doble clic en **Actualizar desde Bybit.bat**.
3. Para ver todo junto → abrí **Mi Dashboard de Finanzas.html**.

Cualquiera de los dos `.bat` ya deja el Dashboard actualizado automáticamente al terminar.
